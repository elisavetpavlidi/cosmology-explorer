READ THE CROSSING

The mode starts inside.

Before exit, k > aH: the mode’s physical scale 1/k is smaller than the comoving Hubble radius.

Convention: we compare the reduced scale 1/k with 1/(aH), using c = 1. The full wavelength is 2π/k.

Model: constant ε, then an instantaneous transition to radiation or matter. This illustrates crossing; it is not a reheating calculation.

Numerical checks

Composite Simpson integration in ln a gives cosmic time. Age integrates back to a = 10⁻¹² with an asymptotic tail. Only the expanding branch connected to today is shown if E² becomes non-positive.

Analytic benchmarks: radiation t₀H₀ = ½; matter = ⅔; Milne = 1; de Sitter has no finite Big Bang age. For flat matter + Λ, an analytic age formula provides another check.

The fiducial values (Ωm,₀ = 0.315, Ωr,₀ = 9.2 × 10⁻⁵, H₀ = 67.4) are illustrative, not a live cosmological fit.
